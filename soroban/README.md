# そろばん帳 - 個人事業主のかんたん帳簿

和風・水彩画風デザインの、フリーランス・個人事業主向けかんたん帳簿アプリです。
サーバーやアカウント登録は不要で、データは端末内（ブラウザのローカルストレージ）に保存されます。インストールしてホーム画面から開けます。

※ 特定の会計サービス・ブランドとは関係のない、オリジナルデザインのアプリです。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `soroban` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- 月を「前月 / 翌月」またはタップで年月選択して移動
- 「記帳」から 日付・種別（収入/支出）・勘定科目・摘要・金額 を入力して記録
- 月の収入・支出・損益をひと目で確認
- 「損益レポート」で今月の勘定科目別の内訳（円グラフ）と半年の推移（棒グラフ）を確認
- メニューからデータの書き出し（JSON / CSV）・読み込み・全削除
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## 勘定科目

- 収入: 売上, 雑収入
- 支出: 仕入, 外注費, 通信費, 交通費, 消耗品費, 地代家賃, 水道光熱費, 接待交際費, 広告宣伝費, 支払手数料, 雑費

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/soroban/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - 和風・水彩画風のスタイルとアニメーション
- `js/app.js` - アプリのロジック（データ保存・グラフ描画）
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

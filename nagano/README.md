# 信州まちしるべ

長野県の**全77市町村（19市・23町・35村）**の魅力・名物・観光スポット・お店・道の駅の有無・ご当地そば・住民の人柄と土地の特徴を、一覧でも1件ずつでも調べられる**完全無料**のWebアプリ（PWA）です。

広告なし・登録不要・課金なし。データはすべてアプリに同梱されているため、一度開けば**オフラインでも動きます**。訪問記録は端末内（localStorage）にのみ保存され、サーバーには送信されません。

## できること

### 🗾 一覧と地図
- 市町村名・よみ・名物・ご当地そば・観光地名・お店の名前など、**全項目を横断して検索**
- しぼり込み：**地域（10圏域）／市・町・村／道の駅あり／美術館・博物館あり／お気に入り／まだ行っていない**
- 並び替え：地域ごと・五十音順・人口順・面積順
- カードの左のふちと市／町／村のしるしは、地図と同じ水彩の色でそろえています
- カードをタップすると詳細シートが開き、**「前／次」で隣の市町村へ**そのまま移動できます（キーボードの ←→ にも対応）
- **「📋 一覧」「🗾 地図」を切り替え**られます。地図は長野県の実際の行政区域で、市町村をタップするとその市町村の情報が開きます
  - 淡い水彩の塗り分け（市＝都会の鼠色・町＝若草・村＝山吹）。行った市町村は緑のふち、条件に合わない市町村はうすい色に
  - **市町村名を地図上に表示**（重なるものは省き、拡大すると増えます。しぼり込み中はその市町村だけ、タップした市町村は必ず表示）
  - 指でなぞって移動、二本指または＋−で拡大縮小、⟲で全体に戻る
  - 地域をしぼり込むと、その地域に自動で寄ります

### 市町村の詳細でわかること
| 項目 | 内容 |
| --- | --- |
| ✨ この土地の魅力 | その市町村がどんな場所かを数行で |
| 🍎 名物・特産 | 食べもの・工芸・農産物 |
| ⛩️ 観光スポット | 3〜6か所を一言解説つきで |
| 🖼 美術館・博物館 | 県立館から村立の資料館、私設館まで（収録がない市町村は探すリンクを表示） |
| 🛍️ お店・立ち寄りどころ | 名物が買える／食べられる場所 |
| 🚗 道の駅 | **あり／なし**と、ある場合は駅名 |
| 🍜 ご当地そば | その土地のそばの名前と、つゆ・つなぎ・食べ方の違い |
| 🧑‍🤝‍🧑 住民の人柄 | よく語られる気質を3つのキーワード＋解説で（例：職人気質・負けん気が強い・几帳面） |
| 👥 住民と土地の特徴 | 気候、産業、成り立ち |
| 📊 基礎データ | 人口（約）・面積・所属地域 |

**観光スポット・美術館と博物館・お店・道の駅・ご当地そばの各項目には、そのまま開ける「🗺 地図」「🔎 検索」のリンク**が付いています。市町村単位の「地図で見る」「公式サイトを探す」も用意しています。

施設ごとの公式URLは移転・閉店で変わるため、地名を添えた地図検索・Web検索を開く方式にしています（リンク切れが起きません）。

### 🧭 地域
北信・長野・北アルプス・松本・木曽・諏訪・上伊那・南信州・上田・佐久の**10地域**から探せます。地域ごとの制覇ぐあいもバーで表示。

### 🍜 そば・道の駅
- **ご当地そば**：77市町村ぶんのそばを地域別に一覧（戸隠そば、富倉そば、すんきそば、高遠そば、行者そば、とうじそば、唐沢そば、タチアカネ、赤そば……）
- **道の駅**：道の駅がある市町村（駅名つき）と、ない市町村を分けて一覧
- **美術館・博物館**：105館を市町村別に一覧
- **名物さがし**：同じ名物を持つ市町村どうしをまとめて表示

### 🚩 記録
- 訪れた市町村に「行った」を付けると、**77市町村の制覇率**と地域別の進み具合が記録されます
- 「きょうの一市町村」は、**まだ行っていない市町村**から選ばれます

## 使い方（そのまま試す）

リポジトリのルートで、

```
python3 -m http.server 8000
```

を実行し、ブラウザで `http://localhost:8000/nagano/` を開いてください。

スマートフォンで開いて「ホーム画面に追加」すると、アプリとして起動できます（Androidはインストールバナー、iOSはSafariの共有メニューから）。

## ファイル構成

```
nagano/
├── index.html              画面の骨組み（4タブ構成）
├── css/style.css           和風・水彩画風のスタイル（ライト／ダーク対応）
├── js/data.js              全77市町村のデータ（このアプリの中身）
├── js/map.js               地図のSVGパス（scripts/make_map.py が生成）
├── js/app.js               検索・しぼり込み・詳細シート・記録の処理
├── manifest.webmanifest    PWA設定
├── sw.js                   オフライン用のService Worker
├── icons/                  アプリアイコン一式
├── scripts/make_icons.py   アイコンを作り直すスクリプト（Pillowが必要）
└── scripts/make_map.py     地図データを作り直すスクリプト
```

データを直したいときは `js/data.js` を編集してください。1市町村が1オブジェクトで、キーの意味は次のとおりです。

| キー | 意味 |
| --- | --- |
| `n` / `k` / `t` | 名称 / よみ / 種別（市・町・村） |
| `r` | 地域ID（`REGIONS` に対応） |
| `pop` / `area` | 人口（人） / 面積（km²） |
| `c` / `charm` | キャッチコピー / 魅力の説明 |
| `m` | 名物・特産（配列） |
| `s` / `shop` / `mus` | 観光スポット / お店 / 美術館・博物館（`[名前, 説明]` の配列） |
| `eki` | 道の駅名の配列（空配列＝道の駅なし） |
| `soba` | `[そばの名前, 説明]` |
| `kg` / `kgt` | 住民の人柄のキーワード（配列） / その解説 |
| `p` | 住民と土地の特徴 |

## 地図データについて

`js/map.js` は、国土交通省 国土数値情報「行政区域データ 2025年版」（CC BY 4.0）をもとにした GeoJSON を、`scripts/make_map.py` で SVG パスに変換したものです。作り直すときは、境界の GeoJSON（長野県＝都道府県コード20）を用意して次を実行します。

```
python3 scripts/make_map.py path/to/municipalities.geojson
```

表示のために境界を簡略化しているため、正確な境界を示すものではありません。二次利用の際は出典の表示が必要です。

## 情報についてのおことわり

- 人口はおおむね2020年国勢調査の水準、面積は概数です。規模感の目安としてご覧ください。
- 美術館・博物館は、確度の高いものだけを収録しています。収録のない市町村にも小さな郷土資料館がある場合があるため、アプリ内の「館をさがす」リンクからご確認ください。
- 道の駅・お店・美術館・イベントは、新規開業や休業、季節や曜日による変更があります。**お出かけ前に各市町村・施設の公式情報でご確認ください。**
- アプリ内の地図は国土数値情報「行政区域データ 2025年版」（CC BY 4.0）を加工したもので、境界を簡略化しています。
- 「住民の人柄」は、その土地の歴史や産業から一般に語られる気質の傾向をまとめたものです。個々の住民を評価するものではなく、一人ひとりに当てはまるものでもありません。
- 登山や火山周辺（御嶽山など）へ向かうときは、最新の気象・火山・道路情報の確認をお願いします。

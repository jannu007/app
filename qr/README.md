# QR早見帖 - 無料のQRコードスキャナー

カメラでかざす、または画像を読み込むだけでQRコードを瞬時に読み取れる完全無料のアプリです。
アカウント登録は不要で、映像や画像はこの端末（ブラウザ）内だけで処理されます。インターネットにアップロードされることは一切ありません。インストールしてオフラインでも使えます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `qr` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。
カメラ機能を使うには HTTPS（またはlocalhost）での接続が必要です。

## 主な機能

- **カメラスキャン**: QRコードを枠内に収めるだけで自動検出。フロント/バックカメラの切り替えにも対応
- **画像から読み取り**: スクリーンショットなどの画像ファイルをドラッグ&ドロップ、または選択して読み取り
- **内容の自動判定**: URL・メール・電話番号・SMS・Wi-Fi接続情報・連絡先(vCard/MECARD)・テキストを判定し、開く/発信する/コピーなど最適な操作ボタンを表示
- **履歴**: 読み取った内容を端末内に自動保存。あとから見返してコピーや再表示が可能
- **オリジナルQRコード作成**: 好きなテキストやURLから、色・サイズ・誤り訂正レベルを指定してQRコードを作成し、PNGとして保存
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## しくみ・プライバシー

このアプリはすべてブラウザ内で完結する静的Webアプリです。QRコードの読み取り・作成は、以下のオープンソースライブラリを使ってブラウザ内（JavaScript）だけで行われ、映像や画像・作成したQRコードの内容はどこにもアップロードされません。

- [jsQR](https://github.com/cozmo/jsQR)（Apache-2.0） - カメラ映像・画像からのQRコード読み取り
- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)（MIT） - QRコードの新規作成

これらはCDNを使わず `vendor/` フォルダにビルド済みファイルとして同梱しているため、オフラインでも動作します。詳しいライセンス表記は [`vendor/LICENSES.md`](./vendor/LICENSES.md) を参照してください。

カメラ映像・読み取り履歴・作成したQRコードは、すべてこの端末（ブラウザのlocalStorage）内にのみ保存されます。

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/qr/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。カメラ機能はHTTPS配信時のみ利用できます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - 和紙・墨・朱色（判子）をテーマにしたスタイル
- `js/app.js` - アプリのロジック（スキャン・履歴・作成）
- `vendor/` - 同梱ライブラリ（jsQR / qrcode-generator）とライセンス表記
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

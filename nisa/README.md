# つみたての桜 - 新NISAシミュレーター

和風・水彩画風デザインの、初心者向け新NISA資産運用シミュレーターです。
毎月の積立額・想定利回り・積立期間を動かすと、地面から生えた桜の木が評価額に応じて育っていき、評価額が1億円に達すると満開になるアニメーションで資産の成長が表示されます。
サーバーやアカウント登録は不要で、入力値は端末内（ブラウザのローカルストレージ）に保存されます。インストールしてホーム画面から開けます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `nisa` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- つみたて投資枠・成長投資枠を分けて、毎月の積立額・一括投資額・想定利回り（堅実/標準/積極のプリセット付き）・積立期間をスライダーで調整
- 評価額に応じて地面から桜の木が育つモーショングラフィックス（評価額1億円で満開）
- 元本と評価額の推移を示すアニメーション付き成長グラフ
- リアルタイム相場（オルカン・S&P500の実績年率）を想定利回りに反映する機能（有効/無効を切り替え可能、通信できない場合は長期の歴史的平均を参考値として使用）
- 選択した銘柄の推移グラフ表示
- 非課税のメリットを課税口座と比較して可視化（節税額を自動計算）
- 用語集・使い方モーダルで複利やNISAの用語をやさしく解説
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## 免責事項

シミュレーション結果は入力条件にもとづく複利計算の目安であり、将来の運用成果や元本を保証するものではありません。実際の投資は各金融機関の情報をご確認のうえ、ご自身の判断で行ってください。

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/nisa/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - 和風・水彩画風のスタイルとアニメーション
- `js/app.js` - アプリのロジック（複利シミュレーション・桜の木/グラフ描画・アニメーション・リアルタイム相場取得）
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

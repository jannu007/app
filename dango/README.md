# つるん団子

同じ色の団子を4つ以上つなげて消す、無料の落ち物パズルゲームです。広告なし・登録不要・サーバー通信なしで、インストールすればオフラインでも遊べます。

## 遊び方

- 上から2つ1組の団子が落ちてきます。
- 同じ色をタテヨコに4つ以上つなげると消えて得点になります。
- 消えたあとに団子が落ちて連続で揃うと「連鎖」となり、スコアが大きく増えます。
- 盤面の上まで団子が積み上がるとゲームオーバーです。

### 操作方法

| 操作 | キーボード | タッチ |
| --- | --- | --- |
| 左右移動 | ← → | ◀▶ボタン / 盤面を左右にスワイプ |
| 回転 | ↑ or X（右回転）/ Z（左回転） | ↺↻ボタン / 盤面をタップ |
| ソフトドロップ | ↓ | ▼ボタン |
| ハードドロップ | スペース | ⏬ボタン / 盤面を下にスワイプ |
| 一時停止 | P / Esc | ⏸ボタン |

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク不使用）、Canvas 2D でゲーム描画
- ゲームロジック・アイコンともにすべてオリジナルで作成（既存の版権キャラクターや商標は使用していません）
- ハイスコアは端末内の `localStorage` にのみ保存（サーバー送信なし）
- PWA対応（`manifest.webmanifest` / `sw.js`）でホーム画面に追加・オフライン起動が可能
- フォントは Google Fonts の「Shippori Mincho」「Zen Maru Gothic」（いずれも SIL Open Font License、商用利用可）

## ファイル構成

- `index.html` - ゲーム画面
- `css/style.css` - スタイル
- `js/app.js` - ゲームロジック・入力処理・描画
- `manifest.webmanifest` / `sw.js` - PWA設定
- `icons/` - アプリアイコン一式
- `scripts/make_icons.py` - アイコン生成スクリプト（Pillow使用）

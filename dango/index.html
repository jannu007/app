遊び方

上から2つ1組の団子が落ちてきます。同じ色を4つ以上タテヨコにつなげると消えて得点になります。

消えた後に団子が落ちて連続で揃うと「連鎖」になり、スコアが大きく増えます。

操作方法

  • 左右移動：矢印キー / ◀▶ボタン / 盤面を左右にスワイプ
  • 回転：↑キー・Xキー(右回転) / Zキー(左回転) / ↺↻ボタン / 盤面をタップ
  • ソフトドロップ：↓キー / ▼ボタン
  • ハードドロップ：スペースキー / ⏬ボタン / 盤面を下にスワイプ
  • 一時停止：Pキー / ⏸ボタン

団子が盤面の上まで積み上がるとゲームオーバーです。レベルが上がるほど落下速度が速くなります。

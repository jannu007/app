# 栞PDF - 無料のPDFページ編集

PDFの結合・並べ替え・削除・回転・分割・透かし追加が全部無料でできる編集アプリです。
サーバーやアカウント登録は不要で、PDFファイルはこの端末（ブラウザ）内だけで処理されます。インターネットにアップロードされることは一切ありません。インストールしてオフラインでも使えます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `pdf` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- **結合**: PDFを複数選択またはドラッグ&ドロップすると、そのままページが1つの作業リストにまとまります
- **並べ替え**: ページカードをドラッグ、または ◀ ▶ ボタンで順序変更
- **削除・回転**: カードごとのミニボタン、または複数選択してまとめて削除・90°回転
- **分割・抽出**: 選択したページだけを新しいPDFとして保存、または1ページずつPDFに分割してZIPで一括ダウンロード
- **透かし・ページ番号**: 任意のテキスト（日本語もOK）を好きな位置・サイズ・濃さ・色で追加。ページ番号は `{n} / {total}` のような書式にも対応
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## しくみ・プライバシー

このアプリはすべてブラウザ内で完結する静的Webアプリです。PDFの読み込み・編集・書き出しは、以下のオープンソースライブラリを使ってブラウザ内（JavaScript）だけで行われ、ファイルはどこにもアップロードされません。

- [pdf.js](https://mozilla.github.io/pdf.js/)（Apache-2.0） - ページのサムネイル表示
- [pdf-lib](https://pdf-lib.js.org/)（MIT） - ページの結合・回転・透かし追加・書き出し
- [JSZip](https://stuk.github.io/jszip/)（MIT/GPL-3.0デュアルライセンス） - 分割したPDFのZIP書き出し

これらはCDNを使わず `vendor/` フォルダにビルド済みファイルとして同梱しているため、オフラインでも動作します。詳しいライセンス表記は [`vendor/LICENSES.md`](./vendor/LICENSES.md) を参照してください。

暗号化（パスワード保護）されたPDFは現在サポートしていません。

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/pdf/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - 和紙・墨・藍色をテーマにしたスタイル
- `js/app.js` - アプリのロジック（読み込み・編集・書き出し）
- `vendor/` - 同梱ライブラリ（pdf.js / pdf-lib / JSZip）とライセンス表記
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

# 免許みちしるべ

自動車免許（普通免許）の取得に特化した、完全無料のWebアプリ（PWA）です。
入校から免許証交付までの道のり、学科試験の〇×問題190問、道路標識31種の図鑑とクイズ、教習の進み具合や費用の記録までを1つにまとめています。
広告なし・登録不要・サーバー通信なしで、インストールすればオフラインでも使えます。

## 4つの機能

### 🗺️ 道のり
- 教習所選びから免許証の交付までを9ステップで表示し、終わったものからチェックできます。
- 進み具合はリング表示で一目でわかります。ステップを開くと、内容と注意点が読めます。
- 次の検定・試験日を入れると残り日数を表示します。
- 入校手続き／検定当日／本免許試験当日の持ち物チェックリスト付きです。

### 📝 学科
- 〇×形式の学科問題を **190問** 収録（10分野、ひっかけ問題20問を含む）。
- **仮免模試**（50問・30分・45問以上で合格）と **本免模試**（95問・50分・86問以上で合格）は、本番と同じ形式で時間を計り、解き終わってから答え合わせをします。
- **おまかせ10問／分野別練習／ひっかけ道場** は1問ごとに解説が出る練習モードです。
- 間違えた問題は自動で **弱点復習** にたまり、出題も苦手な問題が出やすくなる重み付けになっています。
- 分野ごとの正解済み問題数と全体の正答率を記録します。

### 🚸 標識
- 規制標識・指示標識・警戒標識あわせて **31種類** をオリジナルのイラストで収録。タップすると意味と注意点が開きます。
- 4択の標識クイズ（10問）で、似た標識と見分ける練習ができます。

### 🚗 教習記録
- 技能教習（第一段階20項目・第二段階13項目）と学科教習（第一段階10項目・第二段階16項目）の受講済みチェック。
- 費用メモ（項目と金額を自由に追加、目安の内訳の読み込みも可能）と、教習メモの保存。

## 収録している学科問題について

| 分野 | 問題数 |
| --- | --- |
| 標識・標示 | 24問 |
| 通行のルール | 32問 |
| 速度と停止距離 | 15問 |
| 駐車と停車 | 20問 |
| 交差点・信号 | 20問 |
| 安全運転 | 26問 |
| 免許と心得 | 20問 |
| 高速道路 | 14問 |
| 二輪車 | 9問 |
| 事故と応急救護 | 10問 |

道路交通法や交通の教則の一般的な内容をもとに作成したオリジナル問題で、実際の試験問題ではありません。すべての問題に解説が付いています。

## 注意（免責）

- 本アプリは学習用です。教習の項目名・順序・手数料・必要書類は、教習所や都道府県、時期によって異なります。
- 法令は改正されることがあります。手続きや受験の前には、教習所の案内および各都道府県警察の公式情報を必ず確認してください。
- 標識のイラストは、形と色の特徴をつかむための簡略図です。実際の標識とは細部が異なります。

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク不使用）
- データは `js/questions.js`（学科問題）、`js/signs.js`（標識・SVGイラスト）、`js/curriculum.js`（道のり・教習項目・チェックリスト）に分離
- 記録はすべて端末内の `localStorage` にのみ保存（サーバー送信なし）
- PWA対応（`manifest.webmanifest` / `sw.js`）でホーム画面に追加・オフライン起動が可能
- フォントは Google Fonts の「Shippori Mincho」「Zen Maru Gothic」（SIL Open Font License）

## ファイル構成

- `index.html` - アプリ画面（4タブ構成）
- `css/style.css` - スタイル
- `js/questions.js` - 学科問題190問＋分野データ
- `js/signs.js` - 道路標識31種のデータとSVGイラスト
- `js/curriculum.js` - 取得までの9ステップ・教習項目・持ち物・ひっかけワード・費用の目安
- `js/app.js` - 画面制御・出題ロジック・記録の保存
- `manifest.webmanifest` / `sw.js` - PWA設定
- `icons/` - アプリアイコン一式
- `scripts/make_icons.py` - アイコン生成スクリプト（Pillow使用）

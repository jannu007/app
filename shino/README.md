# 志野図鑑 - 志野焼の歴史・種類・名品がわかる図鑑アプリ

志野焼の歴史、土と釉薬、種類（無地志野・絵志野・鼠志野・紅志野／赤志野・練上手）、国宝「卯花墻」などの名品を、イラストとともに解説する完全無料アプリです。
サーバーやアカウント登録は不要で、お気に入り登録の情報のみ端末内（ブラウザのローカルストレージ）に保存されます。インストールしてホーム画面から開けます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `shino` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- **ホーム** - アプリの案内と「志野焼 豆知識」のランダム表示、各コンテンツへのショートカット、お気に入り一覧
- **歴史** - 室町時代の伝承から桃山時代の最盛期、荒川豊蔵による1930年の古窯発見までの年表
- **特徴・種類** - もぐさ土・志野釉（長石釉）の解説と、無地志野・絵志野・鼠志野・紅志野／赤志野・練上手の5種類をイラスト付きで紹介
- **名品ギャラリー** - 国宝「志野茶碗 銘 卯花墻」、重要文化財「志野茶碗 銘 広沢」をイメージイラストと解説文で紹介
- 各項目を「お気に入り」に登録して、ホームからすぐに見返せる
- メニューからお気に入りの書き出し（JSON）・読み込み・全削除
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## 画像について

アプリ内で使用しているイラストは、すべて本アプリのために描き起こしたオリジナルの水彩画風イラストです（`scripts/make_gallery.py` で生成）。実在する文化財の写真ではなく、著作権上の懸念なく無料・商用利用できます。名品ギャラリーの「卯花墻」「広沢」の画像も、解説文をもとにしたイメージイラストであり、実物の再現・複製ではありません。

## 内容の出典について

歴史・種類・名品の解説文は、文化遺産オンライン、三井記念美術館、岐阜県公式サイト、美濃焼伝統工芸品協同組合などの公開情報を参考に作成しています。伝承として語られる部分（人名・逸話など）には諸説あるものが含まれます。正確な情報が必要な場合は、各出典元や専門書籍をご確認ください。

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/shino/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - スタイルとアニメーション
- `js/app.js` - アプリのロジック（タブ切り替え・お気に入り・豆知識）
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `img/` - 図鑑用イラスト画像
- `scripts/make_icons.py` - アプリアイコン生成スクリプト（再生成したい場合のみ使用）
- `scripts/make_gallery.py` - 図鑑用イラスト生成スクリプト（再生成したい場合のみ使用）

# 志野手帖 - 志野焼のうつわを育てる暮らしの記録帳

志野焼をはじめとする、お気に入りのうつわの登録・お手入れ管理・使用記録ができる完全無料アプリです。
サーバーやアカウント登録は不要で、データは端末内（ブラウザのローカルストレージ）に保存されます。インストールしてホーム画面から開けます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `shino` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- **ホーム** - 登録した器の数、目止め待ちの器の数、最近使った器を一覧表示。季節に合わせた器の楽しみ方の提案や、しばらく出番のない器の「そろそろ使ってあげませんか？」リマインドも表示
- **器** - 名前・種類（茶碗／湯呑み／ぐい呑み／皿／鉢／花器など）・窯元や作家・購入日・目止めの有無・メモを登録して管理。タップすればいつでも編集・削除できます
- **お手入れ** - 志野焼特有の「目止め」のやり方、使う前後のお手入れ方法、貫入に景色が育つ楽しみ方、収納のコツなどをまとめたガイド
- **記録** - 器を使った日付・料理や用途・メモを記録。お気に入りの一枚がどんな景色に育ってきたかをあとから振り返れます
- メニューからデータの書き出し（JSON）・読み込み・全削除
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## 志野焼のお手入れについて

アプリ内の「お手入れ」タブの内容は、志野焼をはじめとする土物のうつわ全般に共通する一般的な目安であり、すべての器・釉薬の組み合わせに当てはまるものではありません。窯元や作家によって推奨されるお手入れ方法が異なる場合がありますので、購入時の説明も合わせてご確認ください。

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/shino/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - スタイルとアニメーション
- `js/app.js` - アプリのロジック（データ保存・器管理・使用記録・季節提案）
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

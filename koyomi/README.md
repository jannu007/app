# こよみ手帖 - 無料のスケジュール管理アプリ

月間カレンダーに予定とタスクをまとめて書き込める、ジョルテのような完全無料のスケジュール帳アプリです。
サーバーやアカウント登録は不要で、データは端末内（ブラウザのローカルストレージ）に保存されます。インストールしてホーム画面から開けます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `koyomi` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- **月間カレンダー** - その日の予定・タスクを色分けされた短冊で直接カレンダーに表示（ジョルテのような「書き込み帳」スタイル）。左右スワイプまたは矢印ボタンで月を移動、「今日」ボタンでワンタッチ復帰
- **予定・タスクの追加** - 種別（予定／タスク）、タイトル、日付、終日／時間指定、色分け、メモを設定可能。タスクはチェックで完了にできます
- **その日のアジェンダ** - 選択した日の予定・タスクを一覧表示。タップして編集、ゴミ箱アイコンで削除
- メニューからデータの書き出し（JSON）・読み込み・全削除
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/koyomi/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - スタイルとアニメーション
- `js/app.js` - アプリのロジック（データ保存・カレンダー描画・アジェンダ表示）
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

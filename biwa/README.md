# 弁天文庫（べんてんぶんこ）

黒漆に金の蒔絵で描いた桜と琵琶。縦書き・ルビにこだわった、完全無料・広告なし・登録不要の読書アプリ（インストールできるPWA）です。
本もメモも記録もすべて端末内（IndexedDB / localStorage）に保存され、サーバーには送信されません。

## できること

| 分類 | 機能 |
| --- | --- |
| 読み込み | TXT（UTF-8 / Shift_JIS / EUC-JP / UTF-16 を自動判別）、青空文庫ZIP（ルビあり）、EPUB（DRMなし）、HTML、Markdown、文章の貼り付け、ドラッグ＆ドロップ |
| 青空文庫記法 | ルビ（｜《》）、傍点・傍線・太字・縦中横の注記、大／中／小見出し（目次になる）、字下げ・地付き・字上げ、改ページ、外字（Unicode指定のもの）、底本の奥付 |
| Web小説記法 | `|漢字《かんじ》`、`|漢字(かんじ)`、カクヨム式傍点 `《《》》`、「第一章」などの見出しの自動検出 |
| EPUB | 目次（nav / NCX）、表紙、挿絵、縦書き指定（`page-progression-direction` / CSS）、縦中横・傍点のクラス |
| 表示 | 縦書き／横書き（本に合わせて自動）、ページめくり／スクロール、6書体、文字サイズ・行間・字間・余白、7色（漆・金屏風・生成り・桜・藤・夜桜・墨）、明るさ、めくり効果、横書きの見開き表示、二桁数字と「!?」の自動縦中横 |
| 操作 | タップ（左右で前後・どこでも次へ）、スワイプ、キーボード、マウスホイール、位置のつまみ、前後の章 |
| 書き込み | 4色マーカー、メモ、栞、コピー、辞書で調べる、Markdownへの書き出し |
| 探す・聴く | 全文検索（該当箇所を光らせる）、音読（ルビの読みで発音・読んでいる文に色・自動でページ送り・速さ調整）、自動ページめくり |
| 記録 | 読書時間（自動計測）、一日の目標と桜の輪、連続日数、一週間のグラフ、花暦（18週のヒートマップ）、読む速さの学習、章と本の残り時間の目安、読了のお祝い |
| データ | バックアップの書き出し／読み込み（本文を含めるか選べる）、端末内保存、オフライン動作 |
| インストール | 本棚右上の「アプリをインストール」から1タップ（Android・PCのChrome／Edge）、iPhone・iPadは手順を案内。ホーム画面のショートカット、TXT・EPUB・ZIPを「このアプリで開く」に対応 |

位置は「章番号＋章内の文字位置（ルビの読みは数えない）」で記録するため、文字サイズや画面の向きを変えても同じ場所に戻れます。

## 付属の本

- 『弁天文庫の手引き』…使い方の本（青空文庫記法の見本を兼ねる）
- 『金地の四弦』…このアプリのための書き下ろし短編（完全オリジナル）

## 技術構成

- 素のHTML / CSS / JavaScript（ES Modules、フレームワーク・外部ライブラリなし）
- ZIPの展開はブラウザ標準の `DecompressionStream("deflate-raw")` を使った自作の最小リーダー（`js/zip.js`）
- ページ分割はCSS段組み（縦書きは `writing-mode: vertical-rl` の段組み）。本文はタグを限定して安全なHTMLに変換してから表示（スクリプト・イベント属性・外部画像は取り除く）
- 音読は Web Speech API、読んでいる文や検索結果の強調は CSS Custom Highlight API
- 絵（黒漆に金の蒔絵：桜・琵琶・十二単の袖・霞・切金）・表紙の文様・アイコンはすべてSVG／Pillowで描いたオリジナル
- フォントは Google Fonts の「しっぽり明朝」「Zen オールド明朝」「Zen 丸ゴシック」「Zen 角ゴシック New」「BIZ UDPゴシック」「Klee One」（いずれも SIL Open Font License、商用利用可）

## ファイル構成

- `index.html` - 画面
- `css/style.css` - スタイル
- `js/app.js` - 本棚・リーダーの操作・記録・設定
- `js/reader.js` - 読書エンジン（ページ分割・位置・マーカー・音読の区切り）
- `js/parse.js` - 各形式の読み込みと青空文庫記法の変換
- `js/zip.js` - ZIPリーダー
- `js/db.js` - 端末内保存（IndexedDB）
- `js/art.js` - 表紙絵・自動表紙・花びら
- `js/samples.js` - 付属の本
- `manifest.webmanifest` / `sw.js` - PWA設定
- `icons/` / `scripts/make_icons.py` - アイコンとその生成スクリプト（Pillow）

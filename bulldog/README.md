# ブル手帖 - ブルドッグと暮らす記録アプリ

体重・お散歩・熱中症リスク・お手入れ記録をまとめて管理できる、ブルドッグと暮らす人のための完全無料アプリです。
サーバーやアカウント登録は不要で、データは端末内（ブラウザのローカルストレージ）に保存されます。インストールしてホーム画面から開けます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `bulldog` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- **ホーム** - 愛犬のプロフィール、最新体重、直近7日の散歩状況、次のお手入れ予定を一覧表示。気温・湿度を入力すればその場で熱中症リスクをチェック
- **体重** - 体重の記録と推移グラフ表示。適正体重の範囲を設定すると、今の体重が範囲内かをひと目で確認
- **お散歩** - 散歩時間・気温・湿度を記録。ブルドッグなど短頭種向けに調整した熱中症リスク判定（安全・注意・危険・非常に危険）を自動表示
- **記録** - 通院・投薬・ワクチン・シャンプー・しわ／皮膚のお手入れ・耳そうじ・爪切りなどを記録し、次回予定日のリマインドを表示
- メニューからプロフィール設定・データの書き出し（JSON）・読み込み・全削除
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## 熱中症リスク判定について

ブルドッグ（イングリッシュ・フレンチ・アメリカン等）は短頭種のため、パンティング（口呼吸）による体温調節が苦手で熱中症になりやすいと言われています。このアプリの判定は気温・湿度から算出した簡易的な目安であり、獣医学的な診断ではありません。実際のお出かけの際は、日陰・時間帯・愛犬の様子（過度な喘ぎ、よだれ、ぐったりなど）を必ずあわせて確認してください。異常が見られる場合はすぐに涼しい場所へ移動し、動物病院に相談しましょう。

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/bulldog/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - スタイルとアニメーション
- `js/app.js` - アプリのロジック（データ保存・グラフ描画・熱中症リスク判定）
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

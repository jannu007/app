# うつし鏡 - 無料の顔年齢・肌年齢チェック

顔写真から推定年齢と肌スコアを表示する、完全無料のアプリです。
アカウント登録は不要で、写真はこの端末（ブラウザ）内だけで解析されます。インターネットにアップロードされることは一切ありません。インストールしてオフラインでも使えます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `kagami` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。
カメラ機能を使うには HTTPS（または localhost）での接続が必要です。

## 主な機能

- **カメラ撮影 / 写真の読み込み**: その場で撮るか、手持ちの写真を選ぶ・ドラッグ&ドロップ・貼り付けで読み込み
- **顔の自動検出**: 肌色の分布と目の位置から顔を自動で切り出し。うまくいかないときは枠をドラッグして手動で合わせられます
- **推定顔年齢と肌スコア**: 15〜79歳の推定年齢（幅つき）と、100点満点の総合スコア
- **個人補正**: 実年齢を入れて2回以上記録すると、その人のずれの分だけ結果を補正し、自分に合った表示になります
- **似ている顔タイプ**: 顔の特徴点から輪郭と目鼻立ちの比率を測り、8種類のオリジナルの顔タイプから最も近いものを判定。タイプごとに「このタイプの例」として名前を登録し、結果に表示できます
- **7項目の内訳**: シワ・目元・キメ・ハリ・明るさ・均一さ・クマをレーダーチャートとバーで表示
- **ケアの提案**: 気になる項目の上位3件について、具体的な対策を提示
- **記録と推移**: 結果を端末内に保存し、顔年齢・肌スコアの推移をグラフで確認。サムネイル付きの一覧、JSON書き出し、一括削除に対応
- **撮影品質のチェック**: ピンボケ・暗すぎ・白飛びの写真は結果を出さず、撮り直しを案内します
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## しくみ・プライバシー

HTML と JavaScript だけでできた静的なアプリです。外部サーバーへの送信は一切なく、機内モードのままでも動作します。

解析は2通りの経路があります。顔の特徴点が取れるときは `js/measure.js`、取れないとき（モデルを読めない環境・横顔など）は `js/analyze.js` に切り替わります。特徴点の検出には Google の MediaPipe Face Landmarker（Apache-2.0）を `vendor/` に**同梱**して使っています。同梱なので実行時に外部へ取りに行くことはなく、画像も端末内から出ません。

処理の流れは次のとおりです。

1. **顔をそろえる** — 両目が水平に、目と目の間隔が100画素になるように回転・拡大縮小します。こうすると顔の大小・傾き・撮影距離が変わっても、同じ部位が同じ場所に来ます。
2. **測る範囲を決める** — 額・目尻・目の下・頬・ほうれい線・口元からあごを、その人の特徴点の位置に合わせて切り出します。顔の輪郭の内側から目・眉・唇を除き、髪や眼鏡のように明るさが極端に外れる画素も外します。
3. **正規化する** — グレーワールド仮説による簡易ホワイトバランスで照明の色かぶりを打ち消します。
4. **撮影品質を確かめる** — 顔が小さすぎる（引き伸ばしになる）・ピントが甘い・暗すぎる・白飛びしている写真は、結果を出さずに撮り直しを案内します。
5. **部位ごとに測る** — 線の深さ（しわ・ほうれい線）は、ぼかした画像との差の振幅をその部位自身の明るさで割って求めます。こうすると明るく写っても暗く写っても、同じしわなら同じ値になります。色ムラは大きなぼかしで照明のなだらかな明暗を取り除いてから測り、影の勾配をムラと誤認しないようにしています。
6. **表情を差し引く** — 笑うとほうれい線と目尻の線は深くなり、目は細くなります。表情の強さを検出し、そのぶんを控えめに割り引いたうえで、注意書きと推定の幅で補います。
7. **年齢に換算する** — 各特徴量を 0〜100 に正規化し、年齢との結びつきが強い項目（しわ・目元・ハリ）を重く、体調や環境で動きやすい項目（くすみ・色ムラ）を軽く重み付けします。

乱数は使っていないため、同じ写真からは必ず同じ結果が出ます。

### 顔タイプの判定

肌の解析とは独立したしくみです。顔の特徴点（478点）から次の比率を求め、8種類の顔タイプのうち最も近いものを選びます。すべて頬骨の幅を1とした比率なので、顔の大きさや撮影距離が変わっても同じ値になります。

- 顔の縦横比（額の上端からあご先までの長さ ÷ 頬骨の幅）
- エラの張り（エラの幅 ÷ 頬骨の幅）
- 目の丸さ（目の縦幅 ÷ 目の横幅）
- 目と目の間隔（目頭どうしの距離 ÷ 目の横幅）

画面には測定値と一緒に「標準の目安」も表示します。この目安は正面から写した顔でよく見られるおおよその幅であり、良し悪しを表すものではありません。

### 「このタイプの例」に名前を登録する

8つの顔タイプそれぞれに、そのタイプの雰囲気を思い浮かべやすくする名前を添えられます。アプリの「しくみ」タブから登録するとこの端末だけに反映され、`js/facetype-examples.js` に書き込むとアプリを開いた全員に表示されます。初期状態では空です。

```js
const defaults = {
  suzukaze: ["名前A", "名前B"],   // 涼風のきりり
  ...
};
```

**これは本人との照合ではありません。** このアプリは顔の造作の比率からタイプを分けているだけで、特定の人物と顔を突き合わせているわけではありません。画面にもその旨を明記しています。

実在の芸能人・有名人と顔を照合する機能は提供していません。照合には本人の顔データが必要で、それを同梱することは技術的にも権利的にもできないためです。根拠のない名前を「診断結果」として表示することはしません。また、実在の方の名前を「このタイプの例」として載せるかどうかは、パブリシティ権への配慮を含め、アプリを公開する人の判断になります。

保存した記録（日時・推定年齢・スコア・7項目の値・96px のサムネイル・メモ）は、この端末のブラウザ内（localStorage）にのみ保存されます。アプリ内の「すべて削除」でいつでも消去できます。

### 精度についての注意

しきい値と重みは、実際の顔写真で観測した値の幅にもとづく経験則です。医学的・統計的に検証された推定式ではありません。年齢の正解が付いた顔画像データセットで検証したものではないため、**絶対的な年齢の的中は保証できません**。

検証できるのは一貫性です。同一人物を写した別の写真（解像度違い・回転あり）で、推定年齢が 52歳 と 53歳、各項目もほぼ同値になることを確認しています。

そのうえで、絶対値を自分に合わせるための手段が**個人補正**です。実年齢を入れて記録した回が2回以上あると、その差の中央値のぶんだけ結果をずらします。中央値を使うのは、条件の悪かった1回に引きずられないためです。記録が少ないうちは効き目を弱め、ずらす量にも上限（±15歳）を設けています。

結果は幅（±）つきで表示します。測れなかった部位が多いときや表情が強いときは、幅が広がります。

以下の場合は結果が実際とずれます。画面にも注意書きが出ます。

- **笑顔** — ほうれい線と目尻の線が深くなります。口を閉じた自然な表情が最も正確です
- **美肌加工・フィルター** — 肌の質感が消えるため、実際より若く出ます
- **顔が小さい写真** — 引き伸ばすとしわを測れないため、結果を出しません
- **強い逆光・真上からの照明** — 影が濃くなり、しわが強めに出ます

## ご注意

本アプリは娯楽・セルフチェックを目的としたもので、医学的な診断や治療の判断に用いることはできません。肌トラブルや気になる変化がある場合は、皮膚科などの医療機関にご相談ください。

## ファイル構成

```
kagami/
├── index.html              画面
├── css/style.css           見た目
├── js/measure.js           肌の解析（特徴点で顔をそろえて部位ごとに測る。主経路）
├── js/analyze.js           肌の解析（特徴点が取れないときの代替。肌色と明暗だけで測る）
├── js/facetype.js          特徴点の検出と、顔立ちのタイプ判定
├── js/facetype-examples.js 顔タイプごとの「このタイプの例」に出す名前
├── js/app.js               画面まわりの処理（撮影・調整・描画・記録）
├── manifest.webmanifest    PWA の定義
├── sw.js                   オフライン対応
├── vendor/mediapipe/       同梱の MediaPipe（Apache-2.0。LICENSES.md 参照）
├── icons/                  アプリアイコン
└── scripts/make_icons.py   アイコン生成スクリプト（Pillow が必要）
```

外部ライブラリは、顔の特徴点検出に使う MediaPipe（`vendor/` に同梱、Apache-2.0）のみです。

`vendor/` は約16MBあります。初回の顔タイプ判定時にダウンロードされ（転送量は圧縮後で約7MB）、以後は端末に保存されてオフラインでも動作します。肌の解析だけを使う場合はダウンロードされません。

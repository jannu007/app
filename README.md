# 和風アプリ集

和風・水彩画風デザインで作った、無料で使える静的Webアプリ（PWA）をまとめたリポジトリです。
サーバーやアカウント登録は不要で、データはすべて端末内（ブラウザのローカルストレージ）に保存されます。

`index.html`（このリポジトリのトップページ）から、以下のアプリを選んで開けます。

- **[京の家計帖](./kakeibo/)** - 水彩画風・京都風デザインの、ワンタッチで使える無料の家計簿アプリ
- **[つみたての桜](./nisa/)** - 桜の木が育つように資産の成長を体感できる、初心者向け新NISAシミュレーター
- **[栞PDF](./pdf/)** - PDFの結合・並べ替え・削除・回転・分割・透かし追加が全部無料でできるPDF編集アプリ
- **[ブル手帖](./bulldog/)** - 体重・お散歩・熱中症リスク・お手入れ記録をまとめて管理できる、ブルドッグと暮らす人のための無料アプリ
- **[志野図鑑](./shino/)** - 志野焼の歴史・土と釉薬・種類・名品を、オリジナルイラストとともに解説する無料の図鑑アプリ
- **[つるん団子](./dango/)** - 同じ色の団子を4つ以上つなげて消す、無料の落ち物パズルゲーム
- **[かさね札](./kasane/)** - トランプを1枚ずつ重ねて揃える、無料のクロンダイク・ソリティア

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

をこのフォルダ（リポジトリのルート）で実行し、ブラウザで `http://localhost:8000` を開くとアプリ選択ページが表示されます。
各アプリのフォルダ（`kakeibo/` や `nisa/`）を直接開いても、それぞれ単独のアプリとして動作します。

## 無料で公開する方法（例）

このリポジトリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で、公開元ブランチを `main` に設定するだけで公開できます。公開後は `/`（アプリ選択ページ）、`/kakeibo/`、`/nisa/`、`/pdf/`、`/bulldog/`、`/shino/`、`/dango/`、`/kasane/` のそれぞれにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザで各アプリのURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ選択ページ（トップページ）
- `kakeibo/` - 家計簿アプリ「京の家計帖」一式
- `nisa/` - 新NISAシミュレーター「つみたての桜」一式
- `pdf/` - PDF編集アプリ「栞PDF」一式
- `bulldog/` - ブルドッグ記録アプリ「ブル手帖」一式
- `shino/` - 志野焼の図鑑アプリ「志野図鑑」一式
- `dango/` - 落ち物パズルゲーム「つるん団子」一式
- `kasane/` - クロンダイク・ソリティア「かさね札」一式

各アプリフォルダの中身（`index.html` / `css/` / `js/` / `manifest.webmanifest` / `sw.js` / `icons/` / `scripts/`）は、そのアプリだけで完結した構成になっています。詳しくは各フォルダ内の README を参照してください。

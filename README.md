# 京の家計帖 - かんたん家計簿

水彩画風・京都風デザインの、ワンタッチで使える無料の家計簿アプリです。
サーバーやアカウント登録は不要で、データは端末内（ブラウザのローカルストレージ）に保存されます。インストールしてホーム画面から開けます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `app` フォルダで実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- 日付を「前日 / 翌日」またはタップでカレンダー選択して移動
- 「追加」から 名前・価格・支出/収入 を入力して記録（履歴からワンタッチ再入力も可）
- その日の合計をアニメーション表示
- 「グラフ表示」で今月の内訳（円グラフ）と半年の推移（棒グラフ）を確認
- メニューからデータの書き出し（JSON）・読み込み・全削除
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: このリポジトリの Settings → Pages で、公開元ブランチをこのブランチ（またはmainにマージ後）に設定するだけで公開できます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - 和風・水彩画風のスタイルとアニメーション
- `js/app.js` - アプリのロジック（データ保存・グラフ描画・アニメーション）
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

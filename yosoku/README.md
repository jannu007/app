# 星の羅針盤 - 株価予測シミュレータ

eMAXIS Slim 米国株式(S&P500) と eMAXIS Slim オールカントリーについて、過去の値動きの傾向と、将来の資産推移の予測が分かる無料アプリです。
サーバーやアカウント登録は不要で、入力値は端末内（ブラウザのローカルストレージ）に保存されます。インストールしてホーム画面から開けます。

## 使い方（そのまま試す）

```
python3 -m http.server 8000
```

を `yosoku` フォルダ（このファイルのあるフォルダ）で実行し、ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- **今の傾向**: S&P500・オールカントリー（代替データとしてMAXIS全世界株式(オール・カントリー)上場投信 2559）の直近の年率リターンとボラティリティ（値動きのブレ幅）を、stooq.comまたはYahoo Financeから取得して表示（通信できない場合は長期の歴史的平均を参考値として表示）
- **過去の値動き比較**: 開始時点を100として指数化した、2つのファンドの推移グラフ
- **将来の予測**: 過去の平均リターンとボラティリティをもとにしたモンテカルロ・シミュレーション（乱数を使った幾何ブラウン運動によるシミュレーションを400通り試行）で、はじめの投資額・毎月の積立額・予測期間から、将来の資産額の範囲（中央値・楽観的・悲観的な予測レンジ）と元本割れ確率を算出
- S&P500だけ／オールカントリーだけ／2つを比較、の表示切り替え
- 2つのファンドの想定年率・ボラティリティ・予測結果を並べた比較表
- 用語集・使い方モーダルでモンテカルロ・シミュレーションやボラティリティなどの用語をやさしく解説
- オフライン対応（Service Worker）・ホーム画面にインストール可能（PWA）

## 予測方法について

過去の月次データから算出した平均リターンとボラティリティ（値動きのブレ幅）をもとに、幾何ブラウン運動（Geometric Brownian Motion）による乱数シミュレーションを400通り実行し、各年における資産額の分布（10%〜90%、25%〜75%のレンジと中央値）を算出しています。あくまで過去の傾向にもとづく統計的な試算であり、将来の値動きを予測・保証するものではありません。

## 免責事項

このシミュレーションは、S&P500指数およびMAXIS全世界株式(オール・カントリー)上場投信(2559)の実績（取得できない場合は長期の歴史的平均）をもとにした試算です。実際のeMAXIS Slimファンドの基準価額の値動きとは、為替の影響や信託報酬などにより差が生じます。将来の運用成果や元本を保証するものではありません。実際の投資は各金融機関の情報をご確認のうえ、ご自身の判断で行ってください。

## 無料で公開する方法（例）

このアプリは静的ファイルのみで動くので、以下のような無料ホスティングにそのまま配置できます。

- **GitHub Pages**: リポジトリの Settings → Pages で公開すると、`/yosoku/` 以下でこのアプリにアクセスできます。
- **Netlify / Vercel の無料枠**: リポジトリを連携するだけで自動デプロイされます。

公開後、スマートフォンのブラウザでURLを開き、「ホーム画面に追加」（Androidは自動で表示されるインストールバナー、iOSはSafariの共有メニュー）からインストールできます。

## ファイル構成

- `index.html` - アプリ本体
- `css/style.css` - 夜空・星座モチーフのスタイルとアニメーション
- `js/app.js` - アプリのロジック（相場データ取得・統計計算・モンテカルロ・シミュレーション・グラフ描画）
- `manifest.webmanifest` / `sw.js` - インストール可能にするためのPWA設定
- `icons/` - アプリアイコン
- `scripts/make_icons.py` - アイコン生成スクリプト（再生成したい場合のみ使用）

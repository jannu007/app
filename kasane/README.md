# かさね札

トランプを1枚ずつ重ねて揃える、無料のクロンダイク・ソリティアです。広告なし・登録不要・サーバー通信なしで、インストールすればオフラインでも遊べます。

## 遊び方

- 場札は7列に1〜7枚ずつ、一番上だけ表向きで並んでいます。
- 場札の上には、色違い（赤→黒→赤…）で1つ小さい数字を重ねられます。
- スートごとの組札に、Aから順番に重ねて4種類すべて揃えればあがりです。
- 山札をタップでめくり（1枚 or 3枚、メニューで切替）、山札が空になったら捨て札をタップで山札に戻せます。

### 操作方法

| 操作 | 方法 |
| --- | --- |
| カード移動 | ドラッグして別の場所へ |
| 自動移動 | カードをダブルタップ（ダブルクリック）すると、置ける場所へ自動で送る |
| 山札をめくる | 山札をタップ |
| 手を戻す | ヘッダー下の「戻す」ボタン |
| 自動で仕上げる | 場札がすべて表向きになると使えるボタン |

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク不使用）。カードはDOM要素として描画し、Pointer Eventsでドラッグ＆ドロップを実装
- トランプの絵柄（コーナーのランク・スート表示、中央のスート/文字、裏面パターン）はすべてオリジナルで作成（実在のカードブランドの意匠は使用していません）
- スコア・タイム・手数・ハイスコア等の記録は端末内の `localStorage` にのみ保存（サーバー送信なし）。ゲーム途中の状態も自動保存され、再訪時に再開できます
- PWA対応（`manifest.webmanifest` / `sw.js`）でホーム画面に追加・オフライン起動が可能
- フォントは Google Fonts の「Shippori Mincho」「Zen Maru Gothic」（いずれも SIL Open Font License、商用利用可）

## ファイル構成

- `index.html` - ゲーム画面
- `css/style.css` - スタイル
- `js/app.js` - ゲームロジック・カード描画・ドラッグ操作
- `manifest.webmanifest` / `sw.js` - PWA設定
- `icons/` - アプリアイコン一式
- `scripts/make_icons.py` - アイコン生成スクリプト（Pillow使用）

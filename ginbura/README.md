# 銀ぶら検定

銀座の歴史・老舗・地理・豆知識を扱う、無料のトリビアクイズアプリです。広告なし・登録不要・サーバー通信なしで、インストールすればオフラインでも遊べます。

## 遊び方

- 全24問の中からランダムで10問が出題される4択クイズです。
- 1問あたり制限時間20秒。選択肢をタップして回答すると、正解・不正解とかんたんな解説が表示されます。
- 10問終了後、正解数に応じて「銀座通（つう）度」のランクが表示されます。
- 自己ベストとプレイ回数は端末内に保存されます。

## 出題内容について

歴史（地名の由来・銀座煉瓦街など）、老舗（伊東屋・千疋屋・木村屋總本店・資生堂など実在する銀座の名店）、地理（隣接する街・メインストリートなど）、文化・豆知識（銀ブラ・歩行者天国・柳並木など）から、広く知られている事実をもとに出題しています。

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク不使用）
- 問題データは `js/questions.js` に分離。イラスト・アイコンはすべてオリジナルで作成
- 自己ベスト・プレイ回数は端末内の `localStorage` にのみ保存（サーバー送信なし）
- PWA対応（`manifest.webmanifest` / `sw.js`）でホーム画面に追加・オフライン起動が可能
- フォントは Google Fonts の「Shippori Mincho」「Zen Maru Gothic」（いずれも SIL Open Font License、商用利用可）

## ファイル構成

- `index.html` - クイズ画面
- `css/style.css` - スタイル
- `js/questions.js` - 問題データ（全24問）
- `js/app.js` - クイズ進行ロジック・UI制御
- `manifest.webmanifest` / `sw.js` - PWA設定
- `icons/` - アプリアイコン一式
- `scripts/make_icons.py` - アイコン生成スクリプト（Pillow使用）

# 銀ぶらIQテスト

「銀ぶらして、IQを測ってみよう。」がキャッチフレーズの、無料のクイズアプリです。銀座の実在トリビアと、ひっかけ問題（IQテスト形式）が混ざった全32問から出題されます。広告なし・登録不要・サーバー通信なしで、インストールすればオフラインでも遊べます。

## 遊び方

- 全問の中からランダムで10問が出題される4択クイズです。
- 1問あたり制限時間20秒。選択肢をタップして回答すると、正解・不正解とかんたんな解説が表示されます。
- 10問終了後、正解数に応じて「銀座通（つう）度」のランクと、遊び心たっぷりの「銀ぶらIQ」が表示されます。
- 自己ベストとプレイ回数は端末内に保存されます。

## 出題内容について

- **銀座トリビア（24問）**: 歴史（地名の由来・銀座煉瓦街など）、老舗（伊東屋・千疋屋・木村屋總本店・資生堂など実在する銀座の名店）、地理（隣接する街・メインストリートなど）、文化・豆知識（銀ブラ・歩行者天国・柳並木など）から、広く知られている事実をもとに出題しています。
- **ひっかけ問題／IQテスト形式（8問）**: 仲間はずれ探し、文章中の文字数カウント、不要な情報が混ざった計算問題、数列パズルなど、銀座を舞台にしたオリジナルの論理パズルです。

「銀ぶらIQ」はエンターテインメント目的の数値表示であり、医学的・心理学的なIQ測定ではありません。

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク不使用）
- 問題データは `js/questions.js` に分離。イラスト・アイコンはすべてオリジナルで作成
- 自己ベスト・プレイ回数は端末内の `localStorage` にのみ保存（サーバー送信なし）
- PWA対応（`manifest.webmanifest` / `sw.js`）でホーム画面に追加・オフライン起動が可能
- フォントは Google Fonts の「Shippori Mincho」「Zen Maru Gothic」（いずれも SIL Open Font License、商用利用可）

## ファイル構成

- `index.html` - クイズ画面
- `css/style.css` - スタイル
- `js/questions.js` - 問題データ（トリビア24問＋IQ形式8問）
- `js/app.js` - クイズ進行ロジック・UI制御
- `manifest.webmanifest` / `sw.js` - PWA設定
- `icons/` - アプリアイコン一式
- `scripts/make_icons.py` - アイコン生成スクリプト（Pillow使用）
